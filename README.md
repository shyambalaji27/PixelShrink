## 📌 Overview

**PixelShrink** is a modern, browser-based image compression tool that allows users to reduce image file sizes without uploading images to any external server.

The application uses native browser technologies to compress images locally, ensuring faster processing and better privacy.

---

## ✨ Features

### 🖼️ Image Processing
- Upload real images directly from your device
- Compress JPG/JPEG images instantly
- Before & After image preview
- Display original image size
- Display compressed image size
- Calculate compression percentage
- Download optimized images

### 🎨 User Interface
- Modern glassmorphism design
- Colorful gradient theme
- Responsive layout
- Mobile-friendly interface
- Smooth hover animations
- Professional developer branding

### ⚡ Performance & Privacy
- No API required
- No backend required
- 100% client-side processing
- Images never leave your device
- Fast browser-based compression

## ⚙️ How It Works

```
User Uploads Image
        ↓
JavaScript Reads File
        ↓
Image Loaded into Canvas
        ↓
Compression Quality Applied
        ↓
Compressed Image Generated
        ↓
User Downloads Optimized Image
```
